## ✨ المميزات الرئيسية (Key Highlights)

1. **جدول المباريات والنتائج الحية (Top Matches Scoreboard):**
   * عرض ذكي لجميع مباريات اليوم مقسمة حسب الحالة (مباشر الآن، اليوم، الغد، المنتهية).
   * فلترة فورية حسب الرياضة (كرة القدم، كرة السلة، قتال / WWE، تنس).
   * دعم التبديل التلقائي بين اللغتين (عربي / English) بنسبة 100%.

2. **بوابة حماية وتفعيل لمرة واحدة (Activation Gate Shield):**
   * نظام Lazy Loading يمنع تحميل أو رسم أي وسائط أو سيرفرات في الـ DOM قبل التفعيل.
   * تركيز وتصميم نيون أخضر `#00FF66` متوافق مع أجهزة التحكم عن بعد (TV Box D-pad Remote).
   * حفظ دائم لحالة التفعيل (`is_activated`) في الذاكرة المحلية (`localStorage` و `SharedPreferences`).

3. **تمويه وحماية الروابط البرمجية (XOR + Base64 Obfuscation):**
   * تشفير الروابط الحساسة وسيرفرات البث ديناميكياً لحمايتها من روبوتات الفحص الآلي والهندسة العكسية.

4. **تجربة سينمائية نقية 100% بدون إعلانات منبثقة:**
   * مشغل فيديو مدمج عالي الكفاءة مع دعم البث عالي الاستقرار (HLS / m3u8 / Embeds).
